# Introduction

Welcome to this GitBook guide.

This site shows you how to plan, structure, and publish documentation with GitBook.

It is built for anyone starting a docs space for the first time. It also works as a quick reference when you need the next step fast.

## What you will find here

* [Quick Start Guide](getting-started/quick-start.md) for the fastest path to a live space
* [Installation](getting-started/installation.md) if you want to edit locally
* [Publishing Your Docs](advanced/publishing.md) when you are ready to share your site

## Who this guide is for

* Students building an assignment site
* Writers creating structured product docs
* Teams publishing internal or public knowledge

## How to use this guide

Start with the quick start if you want a working space fast.

Use the deeper sections when you need more control over structure, navigation, or publishing.

If you plan to make your site public, review your page titles, descriptions, and navigation before publishing.
